# Cathie Wood 10-K analysis

Use the shared annual 10-K record generated by `buffett-10k-analysis`; do not fetch a second data source or infer a missing R&D figure.

## Checks

- Revenue growth a year is `(last revenue / first revenue)^(1/4) - 1`; the chosen threshold is 15% or more.
- Latest-year R&D divided by revenue passes at 5% or more.
- If an input is absent, report `not known`, not pass or fail.

## Memo

Write a short Markdown memo with an **Own**, **Watch**, or **Pass** verdict. Focus on whether the record supports an innovation-growth case; do not use a share price, valuation, target, or information outside the script output. Every number must appear in that output.

Source framework: https://github.com/CinderZhang/FAskills/blob/main/financial-researcher/experts/cathie_wood.md

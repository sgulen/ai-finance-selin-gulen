# Benjamin Graham 10-K analysis

Use the shared annual 10-K record generated by `buffett-10k-analysis`; do not fetch a second data source or estimate a missing value.

## Checks

- Latest current ratio, `AssetsCurrent / LiabilitiesCurrent`, must be 2.00 or more.
- Net income must be positive in every reported year.
- Net income must grow from the first reported year to the last.
- If an input is absent, report `not known`, not pass or fail.

## Memo

Write a short Markdown memo with an **Own**, **Watch**, or **Pass** verdict. Use only figures printed by the script and explain liquidity, earnings consistency, and any gap. Do not use a share price, valuation, target, or information outside the script output.

Source framework: https://github.com/CinderZhang/FAskills/blob/main/financial-researcher/experts/benjamin_graham.md

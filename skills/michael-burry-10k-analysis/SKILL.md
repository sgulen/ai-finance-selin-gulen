# Michael Burry 10-K analysis

Use the shared annual 10-K record generated by `buffett-10k-analysis`; do not fetch a second data source or replace a missing value with an estimate.

## Checks

- Operating cash flow must be at least net income in every reported year.
- Latest liabilities divided by equity must be no more than 2.00.
- If an input is absent, report `not known`, not pass or fail.

## Memo

Write a short Markdown memo with an **Own**, **Watch**, or **Pass** verdict. Focus on cash backing, leverage, and the record's blind spots; do not use a share price, valuation, target, or information outside the script output. Every number must appear in that output.
